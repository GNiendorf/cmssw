2. -Ofast IN MkFitCore MAKES NaN FINAL-FIT STATES (write-up for the mkFit developers)
  What: with MkFitCore compiled -Ofast (the ofast-flag tool: -Ofast -fno-reciprocal-math; the release BuildFile intends it,
  see O6-5), MkBuilder::fit_tracks / MkFitter::reFitOutputTracks write non-finite track states for ~3e-4 of the final-fit
  tracks (the MkFitFitProducer path, trackingMkFitFit). MkFitOutputTrackConverter then drops them.
  Why: the two NaN tests of the final fit are written as x != x
      MkFitter.cc (reFitOutputTracks): if (m_Chi2(itrack, 0, 0) != m_Chi2(itrack, 0, 0)) continue;  // trick for the nan
      MkBuilder.cc (fit_tracks, outlier scorer): if (chi2fwd[..] != chi2fwd[..]) chi2fwd[..] = 1000000; (same for chi2bkwd)
    -Ofast implies -ffinite-math-only, under which GCC folds x != x (and std::isnan) to false: the guards vanish, the NaN
    state is copied out (and a NaN chi2 enters the outlier ranking). Lane ref bisected the loss by TU (#pragma GCC optimize
    ("no-finite-math-only")): MkFitter.cc alone restores all of it; -fno-finite-math-only on the whole library likewise.
  Fix (2 lines + a helper, d1-nan-guards 85a2dba): a bit-level NaN test that no flag can fold,
      inline bool isNaN(float x) { union { unsigned int l; float d; } v = {.d = x}; return (v.l & 0x7fffffffu) > 0x7f800000u; }
    used in both places. Physics-neutral without -Ofast (same decision as x != x); with -Ofast it restores the intended behaviour.
  Evidence (same events, replay chain of the LST initial step, stock + #186 + #187, -Ofast MkFitCore, x86-64-v3;
    F/floors/guard_counts.txt; "no guard" = lane ref's r6 chunks, "guard" = this lane's chunks):
    - final-fit reco::Tracks per 100 events: ttbar +52 +57 +66 +58 +45, QCD +70 +58 +52 +49 +61 with the guard:
      +278 of 960,414 (2.9e-4) ttbar, +290 of 987,458 (2.9e-4) QCD. Lane ref: ~30 of them are true tracks per 100 ttbar
      events; MTV of the fit tracks (500 ttbar) .8894 / .0245 / .0116 with the guard vs .8893 / .0245 / .0116 without.
    - stock built WITHOUT -Ofast vs the -Ofast reference, unpaired fit tracks per 100 ttbar events: 64 and 65 without the
      guard (= the NaN tracks) -> 12 and 16 with it, at the v2-vs-v3 level (14 per 100 events). I.e. with the guard the
      -Ofast build and the strict build agree at rounding level; without it they differ by the lost tracks.
    - menu (trackingMkFitFit, CPU, 500 ttbar, job.sh command line): +161 tracks after the HP selection, +60 hltGeneral tracks;
      efficiency / fake / duplicate unchanged at the 1e-4 level (.8854 / .0108 / .0097 both). A small effect, but it is a
      silent loss of good tracks that depends on compiler flags, and NaN chi2 values also enter the outlier ranking.
    - Other x != x / std::isnan tests in MkFitCore (MkFinder.cc building, debug code) are equally folded away under -Ofast;
      the building floors (candidates, all stages) show no -Ofast effect beyond rounding, so there is no sign that
      they fire on these samples, but they deserve the same helper.

4. NEXT ROUND: THE OUTLIER FIX AS A DEVICE-FIT DEVIATION (design; not implemented this round - other lanes own the fit files)
  Stock patch: RecoTracker/MkFitCore branch r7/fitgap-mkfitfit d2a08a4 (= lanes/mkfitfit patch 0001, re-applied cleanly on #186).
  Port (src/alpaka/fit/FitKernels.h, owner: the fit files' lane):
   - RefitConfig (interface/es/ESConfig.h) gets bool edgeOutliers + int outlierRounds, filled by esFill from new ES parameters
     of our ES producer (defaults false / 1 = stock); a DEVIATION D<n> marker at each changed place.
   - removeOutliers (FitKernels.h:477): cut |= (j == 0 && b > 20) || (j == nFH - 1 && f > 20) when edgeOutliers (j = fit order
     index; for j = 0 the forward chi2 comes from the x100 prior, so the backward one decides; vice versa for the last hit).
   - CPU path outliersAndRefit (:544): loop removeOutliers + refit up to outlierRounds times (removeOutliers runs again on
     the refit's chi2f/chi2b except after the last round), exactly as d2a08a4's remap loop.
   - GPU staged path (kStage 3 = outliers, then the refit stages): re-launch stage 3 and the refit stages for rounds 2..N with
     a round argument; tracks with refit[t] == 0 skip. Extra cost bounded by the refit fraction (stock: ~5% of tracks refit).
   - Acceptance: switch ON vs stock + d2a08a4 at the D7-a floor level (replay + TargetValidation with the var_fix stock
     libraries, F/floors/libs/fix); then the O6-1 paired regression check (ttbar + QCD, >= 500 events each; MTV eff/fake/dup vs
     pT/eta/phi/dxy/vxy, high-pT and jets, track counts and length, paired truth, trigger paths, vertices, timing).
