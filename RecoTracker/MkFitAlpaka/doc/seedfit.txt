MkFitAlpaka lane "seedfit" (round 7, 2026-10-04): LST -> mkFit seeds on the device, the bounded option (b') retry (D7-b).
Details of the algorithm and the seed-state numbers: doc/seeds.txt section R7. Option (a) design: doc/seeds_option_a.txt.
Lane report with all run numbers: lanes/mkfit_alpaka/r7_seedfit/REPORT.txt.

HOW TO SWITCH IT ON (no code change; the build module parameters exist since round 6)
  hltInitialStepTrackCandidatesMkFitDevice.lstSeedFit            = True
  hltInitialStepTrackCandidatesMkFitDevice.lstSeedFitOriginPrior = 3   # kHostCreator: option (b')
  hltInitialStepTrackCandidatesMkFitDevice.lstSeedFitPasses      = 1   # field model as AnalyticalPropagator (validated)
  light host seeds (no host seed creator): + hltInitialStepTrajectorySeedsLST.seedStates = False and
  lstSeedFitDropFailed = True (customizeHLTforMkFitAlpaka[Fit]LstSeedsLight sets these two; it sets passes 3).
  Default: OFF (python DEVICE_LST_SEED_FIT = False, build module lstSeedFit = False).

VALIDATION RECIPE (lanes/mkfit_alpaka/r7_seedfit)
