3. STOCK CHECK (how to run)
  The lane area has a PRIVATE instrumented copy of stock MkFitCore (r3_select/CMSSW/src/RecoTracker/MkFitCore, not in
  the package; built for x86-64-v3 -Ofast like the release, vfmadd count identical to the release library). With
  MKFA_SEL_DUMP_DIR set, selectHitIndicesV2 writes one record per candidate (input state iC, propagated state iP, fail
  flag, Bins, wsr, in_gap, hit list) and MkBuilder begin/end_event open/close sel_<seq>.bin; end_event prints the
  dead-path counters (MKFA_SEL_COUNTERS). The check module runs K2 on the same inputs (device EventOfHits built from
  the same hit wrappers, device ES product) and compares.
    MKFA_SEL_DUMP_DIR=<dir> cmsRun test/select_stock_cfg.py sample=ttbar|qcd maxEvents=N backend=serial_sync|cuda_async
  (ONE stream; the stock chain stays on CPU; r3_select/run/run_check.sh wraps it.) The replayed candidates stay
  bit-identical to the HLT (compareCandidatesHLTvsReplay), so the instrumentation does not change stock.

4. RESULTS (100 ttbar + 100 QCD PU200 replay events, 4,801,040 candidate slots; details in r3_select/REPORT.txt)
  serial_sync: everything bit-identical to stock except the mini-propagator limit states (99.3-99.6% bit-exact, 1 ulp);
    selected hit lists identical in 2,066,339 / 2,066,339 candidates with hits (order included), propagated states,
    fail flags, Bins (q_c, dq_track, dphi_track, bin ranges; 1 phi-bin difference in QCD), WSR, in_gap, extras 0 diffs.
  cuda_async (L40): hit lists identical in 2,066,321 / 2,066,340; 14 same set in another order (ddphi near-ties), 5 differ
    (a hit at the dq/dphi preselection edge). WSR/in_gap/extras/fail flags 0 diffs. Source: GPU rounding of the
    inter-layer propagation (prop code): 73% of propagated states bit-exact, max |dpar|/sigma 0.32.
  FMA: stock is -Ofast x86-64-v3; GCC contracts the Bins Matriplex expressions a*b + c*d into fma(c, d, a*b). Found
    offline (r3_select/ana/fma_probe.cc on dumped Bins values) and written as explicit std::fma in computeBins and in
    the vectorized mini propagator; the plain forms matched stock in 54-93% only. Note: CMSSW C++ is built with GCC's
    default -ffp-contract=fast, so plain expressions get contracted at the compiler's choice and that choice moves with
    inlining (seen: a plain-form change in hypotV changed the bitwise result of prop's inlined propagateHelixToR).
