  Port rules followed: stock names, argument order and default arguments; templated on N (tracks per Alpaka thread,
  use mkfitdev::kNN: 1 on GPU, 8 = stock NN on CPU); same operations in the same order. Stock Matriplex vector
  expressions (plane propagation) are written as explicit per-slot loops with the identical per-element arithmetic.
  helixAtRFromIterativeCCS runs its per-slot body as one loop over slots (stock: one loop per step over all slots);
  this keeps it bit-identical to stock on the CPU (the stock loop shape was tried: 11% faster on CPU, no longer
  bit-identical) - see REPORT.txt.
  getS keeps the stock formula: the float cancellation fix (s = 2A / (-B - sign(B) sqrt(B^2 - 4AC))) is NOT applied.

  Phase-2 settings baked in (as stock sets them in MkFitGeometryESProducer): Config::usePropToPlane = true,
  Config::usePtMultScat = true (lane mplex constexpr), Config::useTrigApprox = true, Niter = 5, nSStepsInProp2Plane = 2.

    MPlexLS<kNN> err; MPlexLV<kNN> par; MPlexQI<kNN> chg; ... (load N_proc <= kNN tracks)
    propagateHelixToRMPlex(err, par, chg, msRad, outErr, outPar, failFlag, N_proc, pf);          // building, barrel layer
    propagateHelixToZMPlex(err, par, chg, msZ, outErr, outPar, failFlag, N_proc, pf);            // building, endcap layer
    kalmanPropagateAndComputeChi2Plane(err, par, chg, msErr, msPar, nrm, dir, pnt, chi2, propPar, failFlag, N_proc,
                                       pf, propToHit);                                          // hit tests
    kalmanPropagateAndUpdatePlane(err, par, chg, msErr, msPar, nrm, dir, pnt, outErr, outPar, failFlag, N_proc, pf,
                                  propToHit);                                                   // candidate update
    propagateHelixToPlaneMPlex(...) + kalmanOperationPlaneLocal(KFO_Calculate_Chi2 | KFO_Update_Params | KFO_Local_Cov,
                                  ...) + kalmanCheckChargeFlip(...)                             // backward fit
    kalmanPropagateAndUpdateAndChi2Plane(..., noMatEffPtr)                                      // final fit (no CPE)
  Flags of the Phase-2 LST step (PropagationConfig, MkFitGeometryESProducer.cc:625-635): finding_inter_layer,

  Not ported (not called by the Phase-2 LST step, verified by a call census on real HLT events, see REPORT.txt):
  propagateLineToRMPlex, helixAtRFromIterativeCCSFullJac, the barrel/endcap Kalman flavours (kalmanOperation[Endcap]
  and their update/chi2 wrappers, KalmanUtilsMPlex.icc), kalmanOperationPlane (global-frame plane update), and the
  CPE-correction hook (doCPE + cpe_func, a host std::function) of kalmanOperationPlaneLocal /
  kalmanPropagateAndUpdateAndChi2Plane. The final fit DOES use that hook for every pixel hit (PixelCPETemplateReco).
