MkFitAlpaka lane "mplex": Matriplex and math on Alpaka (round 1, 2026-10-03)
==========================================================================

WHAT IT IS
  A portable (host + every Alpaka backend) transliteration of stock mkFit's Matriplex and of the vdt/Config math that
  propagation, Kalman update and hit binning use. Reference: RecoTracker/MkFitCore of CMSSW_20_1_0_pre2.
  Same classes, same API, same element layout, same operations in the same order. Header-only.

  interface/matriplex/
    MatriplexCommon.h    idx_t, MPLEX_SIMD (lane-loop pragma: "GCC ivdep" on host, nothing on device), symOffset(i,j)
                         (closed form of stock gSymOffsets: no global table on device), internal::sincos4.
    Matriplex.h          mkfitdev::Matriplex::Matriplex<T, D1, D2, N>   element (n,i,j) at fArray[(i*D2+j)*N + n]
                         + all stock free functions: operators, abs/sqr/sqrt/hypot/sin/cos/tan/atan2, fast_* (vdt),
                         sincos4, min_max/min/max, multiplyGeneral, multiply (3x3, 6x6), invertCramer (2, 3),
                         invertCholesky (3).
    MatriplexSym.h       mkfitdev::Matriplex::MatriplexSym<T, D, N>   packed lower triangle, fArray[symOffset(i,j)*N+n]
                         + setDiagonal3x3, subtract, addNoiseIntoUpperLeft3x3, invertUpperLeft3x3, ReduceFixedIJ,
                         multiply (sym x sym, 3 and 6, via std_sym_*.ah), invertCramerSym (2, 3), invertCholeskySym (3).
    Matrix.h             typedefs templated on N, as stock Matrix.h: MPlexLL<N>, MPlexLV<N>, MPlexLS<N>, MPlexHH<N>,
                         MPlexHV<N>, MPlexHS<N>, MPlex5V/5S/55/56/65<N>, MPlex22/2V/2S<N>, MPlexLH/HL<N>,
                         MPlex52/L2/H2/2H<N>, MPlexQF/QI/QUI/QH/QUH/QB<N>; LL = 6, HH = 3;
                         kNNCpu = 8 (stock NN of the x86-64-v3 build), kNNGpu = 1;
                         mkfitdev::MPlex<T,D1,D2,N>, mkfitdev::MPlexSym<T,D,N>, mkfitdev::MatriplexSym<T,D,N> aliases.
    MatrixSTypes.h       device-usable, storage-compatible stand-ins for the ROOT SMatrix typedefs of stock
                         MatrixSTypes.h: SVector<T,D>, SMatrix<T,D1,D2> (row-major), SMatrixSym<T,D> (packed lower
                         triangle = ROOT MatRepSym order = Matriplex order), typedefs SMatrixSym66 ... SMatrix62,
                         diagonalOnly. Storage + element access only (no algebra). Included by Matrix.h.
                         For per-track states in device memory: e.g. plex.copyIn(n, state.errors.Array()).
    MatriplexBackend.h   for Alpaka-compiled code only: ALPAKA_ACCELERATOR_NAMESPACE::mkfitdev::kNN (1 on CUDA/ROCm,
                         8 on CPU backends) and aliases so that stock spellings work unchanged inside
                         ALPAKA_ACCELERATOR_NAMESPACE::mkfitdev: Matriplex::, vdt::, Config::, Const::, MPlexXX<N>,
                         hipo, sincos4, sqr, cube, squashPhi*, getPhi, getTheta, getEta, getRad2, ...
    MatriplexOps.h       generic dense similarity similarityLL(A, S, out) = A S A^T (6x6, S/out symmetric), generated
                         with stock GenMul.pm like MultHelixProp/MultHelixPropTransp but without a sparsity pattern.
    std_sym_3x3.ah, std_sym_6x6.ah             stock files (already N-generic: they index a[i*N+n]).
    SimilarityLL.ah, SimilarityLLTransp.ah     generated by gen/gen_similarity.pl.
    gen/                 stock GenMul.pm (+ one added method, dump_multiply_portable), gen_mul.pl, GenMPlexOps.pl,
                         Makefile; gen_similarity.pl; gen_portable_ops.sh.
  interface/math/
    vdtMath.h            mkfitdev::vdt:: fast_sincosf, fast_sinf, fast_cosf, fast_tanf, fast_atanf, fast_atan2f,
                         fast_logf, fast_isqrtf (+ fast_approx_isqrtf, isqrtf): vdt 0.4.3 float code verbatim; bit
                         reinterpretation via __float_as_uint/__uint_as_float on device, memcpy on host.
    Config.h             mkfitdev::Const (PI, TwoPI, PIOver2, ..., sol, sol_over_100), mkfitdev::cdist,
                         mkfitdev::Config (Niter, useTrigApprox, nSStepsInProp2Plane, Bfield, mag_*, bFieldFromZR,
                         nMaxTrkHits, m_nphi, usePhiQArrays, hit bonus/penalty constants, seed-cleaning and
                         duplicate-removal constants). usePropToPlane and usePtMultScat are constexpr true (stock:
                         runtime globals that MkFitGeometryESProducer sets to true for every Phase-2 geometry).
    MathUtils.h          hipo, hipo_sqr, sincos4 (Matrix.h), sqr, cube, squashPhiGeneral, squashPhiMinimal, getRad2,
                         getInvRad2, getPhi, getTheta, getEta (3 overloads), getHypot, getRadErr2, getInvRadErr2,
                         getPhiErr2 (Hit.h).

INTERFACE FOR OTHER LANES
  Device code (namespace ALPAKA_ACCELERATOR_NAMESPACE::mkfitdev):
      #include "RecoTracker/MkFitAlpaka/interface/matriplex/MatriplexBackend.h"
      template <int N> ALPAKA_FN_ACC void f(MPlexLS<N>& err, MPlexLV<N>& par) {
        MPlexQF<N> s, c;  Matriplex::fast_sincos(par.ReduceFixedIJ(4, 0), s, c);   // as stock
        Matriplex::invertCramerSym(...);  float b = Config::Bfield;  vdt::fast_atan2f(y, x);  ...
      }
      ... f<kNN>(...)   // kNN = tracks per Alpaka thread: 1 on GPU, 8 on CPU
  Host code / headers outside the Alpaka namespace: include Matrix.h (and math/*.h) and use ::mkfitdev::.
  The class itself is mkfitdev::Matriplex::Matriplex<T,D1,D2,N> (stock: ::Matriplex::Matriplex), so stock code that
  writes Matriplex::multiplyGeneral, Matriplex::idx_t, Matriplex::min_max ... transliterates verbatim.
  Free functions are found by ADL as in stock (multiply(a,b,c), hypot(a,b), fast_atan2(y,x), ...).

  Differences from stock (all deliberate, none changes a result):
    - no intrinsics branch (stock CMSSW builds do not enable MPLEX_USE_INTRINSICS either);
    - slurpIn is the stock generic (non-gather) variant: element i of lane j = arr[i + vi[j]], vi in units of T;
    - unsupported dimensions are static_asserts instead of runtime exceptions;
    - vdt-backed methods are float only (static_assert), as mkFit uses them;
    - MatriplexSym::operator= is an element loop instead of memcpy;
    - alignment: alignas(32) (stock MPLEX_ALIGN for AVX2) when N*sizeof(T) is a multiple of 32, natural otherwise;
      C++17 new handles it, no aligned allocation helper is needed;
    - MatriplexVector / aligned_alloc64 are not ported (unused by the CMSSW chain).

  Generated .ah products (prop lane): the stock .ah standard branches already work for any N. To get the portable
  form (MPLEX_SIMD lane loop, no intrinsics branch), run
      interface/matriplex/gen/gen_portable_ops.sh <out dir>
  which regenerates all 31 stock GenMPlexOps.pl products; their expressions were checked identical (whitespace
  aside) to the standard branch of the release's .ah files.

HOW TO RUN THE TESTS
  source /cvmfs/cms.cern.ch/cmsset_default.sh; export SCRAM_ARCH=el9_amd64_gcc13
  cd <area>/src && eval $(scramv1 runtime -sh) && scram b -j 8
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexSerialSync          # CMSSW default flags
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexCudaAsync
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexStrictSerialSync    # -ffp-contract=off, nvcc -fmad=false
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexStrictCudaAsync
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexCpuBench            # CPU port vs stock, default flags
  $CMSSW_BASE/test/$SCRAM_ARCH/testMkFitAlpakaMplexCpuBenchOfast       # CPU port vs stock, stock MkFitCore flags
  (use CUDA_VISIBLE_DEVICES to pick the L40 (0) or the L4 (1)).

  test/alpaka/test_mplex.dev.cc + test_mplex_stockref.cc + test_mplex_ops.h: 23 ops (all multiply/inverter variants,
  invertUpperLeft3x3, the generic similarity, every vdt and std Matriplex transcendental, element-wise operators, scalar
  helpers, data movement incl. slurpIn and SMatrixSym66 <-> plex) on 2048 random tracks each with realistic
  magnitudes (track/hit covariances built as L L^T with per-parameter scales, Jacobian-like matrices, angles/radii/z
  in detector ranges). Each op runs (a) in an Alpaka kernel with N = kNN and (b) on the host with the port at N = 1,
  and is compared element by element with STOCK mkFit at N = 8 on the host (vendored verbatim copy of
  MkFitCore/src/Matrix.h + Matriplex/ in test/alpaka/mplex_stock/, because SCRAM's private-header check forbids
  including another package's src/; stock vdt; stock mkfit helpers).
  Printed per op: bit-identical fraction, ulp histogram, max ulp, max element-wise and normwise relative diff.
  It also checks that the mkfitdev S-types have the same size and element storage order as ROOT SMatrix (stock
  MatrixSTypes.h typedefs), and that MatriplexSym::copyIn of a ROOT SMatrixSym66 array gives the right elements.
  Pass criterion: Strict builds - bit-identical everywhere (except std:: sin/cos/tan/atan2 on a GPU: device libm);
  default builds - normwise difference < 1e-2 (bug catcher).
  Then benchmarks: 6x6 similarity on 2048 and 262144 tracks, 1 or 16 chained similarities per load; Cramer 2x2/3x3
  inversion with the stock double determinant vs a float-determinant variant (benchmark only, not used elsewhere).
