  HLTrigger.Configuration.HLT_75e33_timing_cff (the release menu = vA menu: HLTrigger and MkFit* are identical to the
  release in vA). The menu schedule is replaced by one Path:
    hltSiPixelRecHits        MkFitAlpakaReplayPixelRecHits (harness): legacy pixel rechits from the SoA, see below
    hltSiPhase2RecHits       the menu's Phase2TrackerRecHits from hltSiPhase2Clusters
    hltInitialStepTrajectorySeedsLST  MkFitAlpakaReplaySeeds (harness): copy of the HLTX seeds with det re-attached
    hltMkFitSiPixelHits, hltMkFitSiPhase2Hits, hltMkFitEventOfHits, hltInitialStepMkFitSeeds,
    hltInitialStepTrackCandidatesMkFit, hltInitialStepTrackCandidates      (menu modules, untouched)
    [fit=1] hltMeasurementTrackerEvent, hltInitialStepTrackCandidatesMkFitFit (MkFitFitProducer),
            hltInitialStepTracksMkFitFit (MkFitOutputTrackConverter = the menu's trackingMkFitFit hltInitialStepTracks)
  EndPath replayEndPath: comparators (compareCandidatesHLTvsReplay by default).
  The three harness modules carry the SAME labels as the menu's, so every menu InputTag resolves to them unchanged.
  Why they are needed (persistence pitfalls, worth knowing for any file-based test):
    - BaseTrackerRecHit pos_/err_ are TRANSIENT: legacy rechits read from a file have position (0,0) and zero errors.
    - TrackingRecHit det() is transient: seeds read from a file have hits without GeomDet (MkFitSeedConverter crashes).
    - SiPixelCluster::originalId() is transient: the menu's SiPixelRecHitFromSoAAlpaka asserts on persisted clusters.
      MkFitAlpakaReplayPixelRecHits recovers the per-module SoA index (exact charge, nearest position, 3 passes),
      validated in-memory against originalId(): 0 wrong out of 3,610,066 clusters (20 ttbar events).
