3. DEVICE ALGORITHM (no sort; no decision depends on atomic order)
  S1 KernelSeedPrepare   thread per input seed: silly flag; region (stock arithmetic, same order); key from the last
                         hit position (device EventOfHits product: HitSoA row layers.hitBase[layer] + index, or the
                         host-packed lastX/Y/Z); atomic count into 5 x 64 x 16 counting bins (region, eta bin, 4 high
                         phi bits) -- bin order == (region, key) order; atomic min/max of the last layer per region.
  S2 KernelSeedScan      one block (128 threads, contiguous chunks): cleanIdx = exclusive scan of !silly (= stock index
                         after erase(), i.e. seed_idx / m_seed_origin_index); bin starts; nKept; region ends
                         (m_seedEtaSeparators); "fix min/max layers"; resets the cands SoA scalars.
  S3 KernelSeedFill      thread per kept seed: atomic slot in its bin (position fixed in S4).
  S4 KernelSeedRank      thread per kept seed: pos = binStart + #{bin members with (key, row) < own}. The stock order is
                         the stable radix order of the key over the cleaned vector, placed region-major; (region,
                         key, input row) reproduces it exactly. Cost O(c^2) per bin, c <= ~10 on PU200.
  S5 KernelSeedInitCands thread per cands row: importSeed (TrackCand(seed): state, chi2, label, status with
                         n_seed_hits/eta_region; HoT chain via cands' seedAddHitIdx; score = getScoreCand(defaults));
                         CombCandidate::reset defaults (best-short score = worst, *_before_bkwsearch = -1, Dormant,
                         pickup layer = last seed layer); rows >= nKept get nCands = 0 (safe for per-seed kernels that
                         loop over the capacity).
  E1 KernelExportScan    one block: stable destination of every seed with candidates (and passed[s], if given).
  E3 KernelExportBestCands thread per seed: TrackCand::exportTrack(true) of the front candidate: state, chi2, score,
                         label, status fields, nOverlaps, hit list = HoT chain walked backwards keeping index >= 0.
  runChainTail: cands filterSeeds (bkwRep, attempt_all_cands = true, minHitsQF of the backward params) -> export of the
                passing seeds (= stock filter compaction + export) -> CleanAlgo flagDuplicates + removeDuplicates.
  Capacities: seed rows = input seeds; seed hits <= 32 (nOverflowHits counts longer seeds; max seen 24); HoT pool
  hotsPerSeed (cands' scalar, overflow bit + counter); TrackSoA rows = seeds (nOverflowTracks/Hits).
  Registers (cuobjdump, block 128): seeds kernels 24-72 registers, hits kernels 24-56, LOCAL = 0 everywhere
  (table: lanes/mkfit_alpaka/r3_seeds/run/registers.txt).

6. NOTES FOR OTHER LANES
  - The engine takes the CandStore product of seedsImport (rows [0, nKept) in stock import order, region-contiguous;
    the region ends and min/max last layers are in the seed table's scalars regionEnd/minLastLayer/maxLastLayer).
  - nKept is a device scalar (seeds.nKept()); per-seed kernels can loop over the capacity (rows >= nKept have no
    candidates).
  - Stock quirk kept: Track::Status::n_seed_hits has 4 bits; LST seeds have up to 24 hits (~1 in 6 has > 15), so
    stock stores nTotalHits & 15. It is read only by qfilter_n_hits / qfilter_n_layers and by
    compactifyHitStorageForBestCand with backward_drop_seed_hits, none of which the LST step uses: no physics effect
    here. Reproduced (CandState::nSeedHits and the status bits hold the truncated value).

1. WHAT THE HOST CHAIN DOES (menu config of hltInitialStepTrajectorySeedsLST: includeNonpLSTSs = True,
   dropOTHitsPurePLS = True, produceTrackCandidates = False, SeedFromConsecutiveHitsCreator)
   T5: seed hits = the sorted TC hits from the second PS-pixel hit on (+ the first PS-pixel hit); T4: one hit per layer
   (PS-strip hits on the first layer dropped); pT3/pT5: ALL hits (pixel + OT); makeSeed = FastHelix(hit1, hit0, origin
   (0,0,0)) + initial errors (default GlobalTrackingRegion: origin r 0.2 cm, half length 22.7 cm, q/p >= 1, angles
   1 rad) + KF with PropagatorWithMaterial over every seed hit (hits refitted with the track-angle TTRH builder);
   state at the last hit. T5/T4 whose makeSeed fails are dropped; pT3/pT5 fall back to the pixel seed. pLS: the
   pixel seed (or makeSeed on its IT hits when dropOTHitsPurePLS applies). MkFitSeedConverter converts each state.
   CONSUMERS of the TrajectorySeeds (hltInitialStepTrajectorySeedsLST): MkFitSeedConverter, MkFitOutputConverter
   (TrackCandidate seed + seedRef, default menu), MkFitOutputTrackConverter (TrackExtra seedRef, trackingMkFitFit
   menu), and the validation-only TrackFromSeedProducer. MkFitSeedWrapper consumers: the build module and both output
   converters (which receive it but do not read it). So the module cannot simply leave the menu: refs are needed.

2. DEVICE SEED FIT (src/alpaka/seeds/LstSeedKernels.h, entry fitLstSeeds in src/alpaka/LstSeeds.dev.cc,
   interface/seeds/alpaka/LstSeedFit.h; host runner + validation dump interface/seeds/alpaka/LstSeedFitRunner.h)
   Thread per seed row of the device seed table (after packSeedsToDevice, before importSeeds: the phase2:1 region
   and the silly check see the new state). Rows without an OT hit (pLS, pT3/pT5 fallbacks) keep the copied pixel
   state. Others: 3-hit helix (first, middle, last seed hit) -> initial (x,y,z,1/pT,phi,theta) at hit 0 with wide
   errors (pos 1 cm^2, sigma(1/pT) = 1/pT + 0.01, angles 0.01 rad^2) -> mkFit Kalman over the seed hits in their
   stored order with kalmanPropagateAndUpdateAndChi2Plane (param field + material; the device final-fit primitive),
   material skipped on the first hit -> state at the last hit replaces params/errors/charge. Options (build module):
   lstSeedFitPasses 3 (fwd/bkw/fwd), lstSeedFitErrScale, lstSeedFitOriginPrior 1/2 (host-creator beam-line prior for
   T5/T4 / all), lstSeedFitDropFailed (light mode), lstSeedFitDump (per-seed host vs device states).
   Registers (cuobjdump, block 64): KernelLstSeedFit REG 226 sm_89, 242 sm_75, 247 sm_80, 250 sm_90, 255 sm_100/120;
   LOCAL 0 everywhere.
   Light host seeds (LST package patch, r6_seeds/patches/0003): LSTOutputConverter seedStates = False skips the seed
   creator (FastHelix + KF): seed hits + a placeholder state on the last hit's det; the device fit then replaces every

   Customise (python, patch 0002): DEVICE_LST_SEED_FIT (False), customizeHLTforMkFitAlpaka[Fit]LstSeeds,

R7. ROUND 7 (lane seedfit, 2026-10-04): OPTION (b') = the host creator's STRUCTURE with mkFit's propagation (D7-b)
   Switch: build module lstSeedFit = True, lstSeedFitOriginPrior = 3 (mkfitdev::lstseeds::kHostCreator),
   lstSeedFitPasses selects the field model (1 = host-like, the validated choice; 3 = the final fit's refitKernelFlags).
   No producer change was needed (both parameters exist); default stays OFF.
   Kernel (src/alpaka/seeds/LstSeedKernels.h fitHostLike, one thread per seed row, N = 1):
   - initialKinematic: FastHelix(outer = seed hit 1, middle = seed hit 0, vertex = GlobalTrackingRegion() origin
     (0,0,0)), double, nominal 3.8 T and 0.3 as stock (pT = 0.0114 rho), z at the vertex from the helix, charge from
     the circle centre; the straight-line branch for rho > 10 TeV equivalents; FastCircle's Riemann-sphere fit is
     replaced by the exact three-point circle (rounding level).
   - initialError: curvilinear diag(C(q/p) = max(sin^2(theta)/ptMin^2, MinOneOverPtError^2) = 1, lambda 1, phi 1,
     xT 0.2^2, yT 22.7^2 sin^2(theta) + 0.2^2 cos^2(theta)) rotated to mkFit CCS at the vertex (Jacobian in the code).
   - buildSeed: ONE forward pass over every seed hit: propagateHelixToPlaneMPlex (the first step origin -> hit 0 as a
     geometry-only step followed by the material step, i.e. 4 path refinements instead of 2), material at EVERY
     destination incl. the first hit (PropagatorWithMaterial applies it at the destination surface), per-module
     material (#186, from the surface MediumProperties), energy loss along the momentum; checkHit = true (the LST
     converter passes no seed comparitor); the plane-local KF update (kalmanPropagateAndUpdateAndChi2Plane without
     propagation); state at the last hit.
   - Host rejections emulated: |dphi| of a step > MaxDPhi 1.6 (rejDPhi), a step against the momentum (rejBackward),
     non-finite parameters per step / non-positive final covariance. Rejected seeds keep the host state (dropped
     with lstSeedFitDropFailed in light mode).
   - Float safety: the exact host prior spans ~1e9 of dynamic range in one update (the host works in double); a
     failure with it is retried once with a capped prior (q/p sigma (1/pT + 0.01) sin(theta), angles 0.1 rad, yT 5 cm;
     counter safeRetry). First version (per-step positivity check, no retry): 32% of the fits failed (pT3/pT5 43%).
   - Field model: with refitKernelFlags (#186 mid-point B + radial kick) the T5/T4 1/pT keeps a bias growing with
     |eta| (median pull vs host +0.08 / +0.60 / +1.15 sigma in |eta| < 0.9 / 0.9-1.6 / 1.6-2.5, smoke2); with B at
     the START of each step and no kick (= the host's AnalyticalPropagator, passes = 1) it vanishes (smoke3).
