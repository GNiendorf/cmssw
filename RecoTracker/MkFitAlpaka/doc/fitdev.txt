1. THE SWITCHES
  D3  mkfitfit 0001 in the device fit (doc/DEVIATIONS.txt D3). MkFitAlpakaFitDeviceProducer / MkFitAlpakaFitProducer:
        edgeOutliers (bool, false = stock), edgeChi2Cut (double, 20), outlierRounds (int, 1 = stock).
      Code: src/alpaka/fit/FitTracks.h FitOptions (runFinalFit argument, carried in FitHitAccess::opt);
        FitKernels.h removeOutliers: cut |= (j == 0 && chi2b > cut) || (j == nFH - 1 && chi2f > cut), j = fit order
        index, chi2b / chi2f = the pass that predicts that hit from all the others (the other pass's chi2 at an end hit
        comes from the x100 prior and says nothing);
        CPU (grouped kernel, fitTrackSingle): outliersAndRefit loops removal + refit outlierRounds times; the last refit
        is not checked again (stock d2a08a4's remap loop with nextRemap = nullptr in the last round);
        GPU (split kernels): stages 3 (removal + reFitIndices), 4, 5 (refit) launched once per round; stage 3 with
        round > 0 only looks at the rows refitted in the previous round (meta refit flag). Extra kernels: 3 per round,
        each a no-op for rows that were not refitted.
      Python: customizeFitDev.customizeFitDevOutliers(process, edge=True, rounds=3, dropBadChi2=True) (= fitgap arm b,
        0001 + 0005); customizeFitDevOutliersFitOnly = D3 alone. It switches every device-fit module, including the
        serial clones of customizeHLTforMkFitAlpakaTargetValidation.
  D4  mkfitfit 0005 in outconv's converter (R7-L2). MkFitAlpakaOutputTrackConverter dropNegativeChi2 (false = stock):
        a candidate whose fit chi2 is negative or not finite is dropped, edm::isNotFinite (bit test, -Ofast safe) ||
        chi2 < 0, placed where stock 0005 puts it (after the posDef check, before Sylvester). Needs customizeOutConv.
  D6  TrackExtra inner/outer states (R7-H3). MkFitAlpakaFitDeviceProducer storeOuterState (false = stock) puts a
        FitOuterState collection (interface/fit/FitOuterStateSoA.h: per fitted row the CCS state + errors at the
        outermost fitted hit = the forward pass's updated state there, pos = its HitOnTrack position, -1 = none);
        MkFitAlpakaOutputTrackConverter outerStates (InputTag, empty = stock) then builds the TrackExtra with
        innerOk/outerOk = true, inner = the fitted state on the first hit's surface (the same TSOS the PCA starts from;
        = stock storeHitStates' innermost state), outer = that state on its hit's module, curvilinear errors and det ids
        - what TrackProducer gives TICL / PF in the KF menu. The per-hit trajParams stay zero (no reader in the menu).
        Cost: one 112 B row per track (device + the framework's host copy); the forward-pass kernels copy the state
        once per fit. Python: customizeFitDev.customizeFitDevStates (after customizeOutConv).
        Product dictionaries: src/classes_def.xml (host) and MkFitAlpakaFormats classes_{cuda,rocm}_def.xml (device).
  Registers: the register gate (test/integ_check_registers.sh) on the D3 build: 214 kernels x 6 archs, LOCAL 0 (PASS).
