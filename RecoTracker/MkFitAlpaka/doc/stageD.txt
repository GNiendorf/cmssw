  1. OT rechits on the device, legacy collection OFF (save ~25 ms producer + ~6 ms of readers' host passes; risk none-low).

     per IOV from SiPhase2OuterTrackerLorentzAngle x local B) writing ONE OT rechit SoA for all OT modules (local x/y,
     errors, global x/y/z, det index, cluster key), shared by: LST input (lane lstin's device producer), the CA OT layers

     Phase2TrackerRecHit1D creation for hits on output tracks (MkFitOutputTrackConverter already builds a NEW
     Phase2TrackerRecHit1D from 4 numbers + det + cluster ref) and on pixel tracks (PixelTrackProducerFromSoAAlpaka).
     Gate: bitwise local position/error and global position vs Phase2TrackerRecHits on every hit (ttbar + QCD), then the
     chain unchanged (LST input identical, mkFit hits identical). Prerequisite: the trkgpu reserve/emplace patch of
     Phase2TrackerRecHits (-45% locally) is a release change, so it is the owner's call; the device path makes it moot.
     Packages touched: RecoLocalTracker (new device producer, local), RecoTracker/LST input, RecoTracker/PixelTrackFitting
     (on-demand OT hits) - D7-e covers LST; the other two need the owner's OK.
  2. Seeds (stage B, lanes seedfit + lstin) - remove hltInitialStepSeeds (16.1) and most of LSTOutputConverter (28.4) on
     the HLT path: device seeds for pLS and LST TCs (one creator, D7-b), LST input from the pixel SoA, and a light
     TrajectorySeed collection (or none) since the HLT reads seed states only through MkFitSeedConverter. Validation keeps
     the full host seeds (hltSeedsForMkFit). Risk med: the pLS inputs LST was tuned on (R6-M2), the O6-1 checks.
  3. Output conversion (stage C, lane outconv) - MkFitOutputTrackConverter 19.9 -> one sparse host module from the device
     TrackSoA (PCA + outer state on the device with the CMSSW field, missing-hit pattern on the device or from a device

     hltMkFitEventOfHitsHost / hltMeasurementTrackerEvent leave the chain's dependency list (MTE stays for CKF).
