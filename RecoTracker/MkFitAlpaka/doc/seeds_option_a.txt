0. WHAT (a) IS
  The host seed state of every LST T5/T4/pT3/pT5 seed comes from LSTOutputConverter (RecoTracker/LST/plugins/
  LSTOutputConverter.cc:282-288): SeedFromConsecutiveHitsCreator::makeSeed with a default GlobalTrackingRegion, then
  MkFitSeedConverter turns the state into mkFit CCS. Option (a) runs THE SAME ALGORITHM on the device, bit-for-bit in
  structure and at rounding level in numbers, so that the host creator (the largest host cost of the step,
  LSTOutputConverter 27.9-34.5 ms per input event at CI shape, roughly half of it makeSeed) can leave the menu without
  any physics change. Option (b') (this round, doc/seeds.txt R7) keeps mkFit's propagation/material model; (a) ports
  CMSSW's. The same component serves the pLS seeds (hltInitialStepSeeds = SeedGeneratorFromProtoTracksEDProducer,
  SeedCreatorPSet seedFromProtoTracks = the SAME creator and PSet values), i.e. lane lstin's stage-B pixel seeds.

4. COST AND PLAN
  - Effort: two lane-rounds. Round 1: components c-h as one header set (namespace mkfitdev::cmsseed), a replay test
    that feeds the host seed hits and compares the device state with the host TrajectorySeed state per seed (local
    params and errors, target |pull| < 1e-3 and identical rejections). Round 2: menu integration with the light
    converter, the O6-1 paired list (should then be at the noise level by construction), val5k.
  - Precision: stock does the helix crossings and Jacobians in double; on the device double costs nothing measurable
    here (~3-6k seeds x ~10 hits per event; the round-6 N = 1 float seed kernel was 1.6 ms of GPU time).
  - Registers: one thread per seed, double 5x5 matrices: expect REG 255 / possible spills: split kernel per step
    (state in global scratch), as the final fit (D4-H1). Block <= 128.
  - Host time removed: makeSeed inside LSTOutputConverter (light converter 21.5 vs full 46.9 ms per tracked event in
    round 6, i.e. ~25 ms per tracked event, ~14-17 ms per input event at CI shape), plus the same for hltInitialStepSeeds
    (19.6 ms per input event, lane lstin) if the pLS seeds use the same component.
  - Risks: HelixArbitraryPlaneCrossing's Newton iteration and its fallback order must be transliterated exactly
    (tilted modules); the curvilinear Jacobian's small-step branches; the creator's FreeTrajectoryState carries the
    field at the vertex, every later step the field at its start point (no midpoint: unlike #186's mkFit refit).
  - What (a) does NOT need: the volume-based field map (the param field covers the tracker), Runge-Kutta, the
    strip CPE refit, the seed comparitor, the region direction check.

5. RECOMMENDATION
  (a) is a bounded, mechanical port (~1300 lines, two rounds) because the field is closed form and the OT refit is the
  identity. It is the only route that removes the host creator with NO physics change by construction. Decision: owner.
